## Performance finding

Profiled the one-row float average/ratio case. `ibis.backends.sql.__init__.py:93` (`compile`) accumulated 11.596 s across 6 calls; `ibis.backends.sql.compilers.duckdb.py:111` / `ibis.backends.sql.compilers.base.py:579,607` (`to_sqlglot`/`translate`) accumulated 11.274 s across 10 calls; `ibis.backends.sql.rewrites.py:350` (`sqlize`) accumulated 9.198 s across 10 calls, with `ibis.common.graph.py:479` (`replace`) at 9.681 s cumulative. Terrine's `terrine/temporal/aggregate.py:448` (`aggregate_window`) accounted for 0.835 s across two calls. This supports moving the tests rather than shrinking already tiny inputs; no library code changed.

The removed guide command `uv run pytest tests/temporal/test_window_aggregates.py -m slow` is replaced by `uv run pytest -q integration/temporal`.
