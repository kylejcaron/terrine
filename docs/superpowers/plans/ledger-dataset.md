## Direct boundaries and error models

- Exact fitting uses the existing type-7 quantile: for sorted non-null observations, `h=(n-1)p`, `j=floor(h)`, `g=h-j`, `Q(p)=(1-g)x[j]+g*x[j+1]` (with the endpoint retained at `g=0`). Domain: finite exact decimal inputs and `0 <= p <= 1`; the replacement fits two decimal128(38,2) observations plus one null training observation under Decimal precision 6, retaining the original exact lower/upper and non-null-count assertions. These are exact decimal equalities, not floating-point tolerances.
- Unknown-eligibility validation consumes a real two-row Ibis relation and the real `CompiledStudy`/`AnchorTable` types. `candidate = excluded_false + unknown + retained`; two null boolean eligibility values retain the original coded refusal and exact aggregate-only context. It invokes the same `validate_compiled_output` used by `Frame._materialize` (`terrine/frame.py:652`), without model construction, source snapshots, or row export.
- Surrogate projection uses tiny immutable `MaterializedFrame` inputs and the real projection/Arrow serialization methods. All selected point/start/end timing support, discarded-expression timing filtering, sampled trial roles, sampling provenance, empty feature selection, and metadata round-trip assertions remain.
- Invalid batch-size validation uses an uninitialized `Dataset` instance intentionally: the positive-integer guard must reject before any owner/backend/read attribute is accessed. It asserts the original stable refusal code, without manufacturing a publication.
